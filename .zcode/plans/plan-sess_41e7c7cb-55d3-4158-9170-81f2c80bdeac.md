# Redesign the opening "curtain ceremony" + first-load polish

**Direction chosen:** Swift brand splash (~1.8s, on-brand tokens) · shows once per device · plus dark-theme skeletons and killing the double loader.

## Why (research summary)
The current `PremiumWelcomeCurtain` (app/src/components/welcome/PremiumWelcomeCurtain.jsx) is a 3.5s theatrical overlay using hardcoded wine/bronze/emerald inline styles that clash with Aura's dark neo-glass cyan theme, replays every new tab (sessionStorage), rotates 3 generic headlines, and chains into a spinner → white-skeleton double load. Everything below reuses the existing design system (figmaTokens.css, Tailwind neo palette, signature easing `cubic-bezier(0.16,1,0.3,1)`, `animate-shimmer`).

## Changes

**1. Rebuild `app/src/components/welcome/PremiumWelcomeCurtain.jsx` (in place, same file/testid/contract)**
- New composition: deep backdrop (`--figma` surface tokens) with a soft radial cyan glow (`rgb(var(--theme-primary-rgb) / α)`) and a subtle palette-ribbon hairline; centered glass card (`bg-white/[0.04]` + `border-white/10` + blur) with ✦ AURA wordmark in brand cyan, kicker "Secured. Fast. Premium.", single headline "Welcome to Aura" (no rotation), subcopy; thin shimmer progress line (`animate-shimmer`); Skip + sound controls top-right.
- Delete: two sliding panels (3.15s sweep), message rotation (`MESSAGE_COUNT`, `TEXT_ROTATION_MS`), pointerdown-anywhere chime trigger.
- Timing: `AUTO_CLOSE_MS` 3200 → 1800; content entrance 600ms fade-up with the signature easing; exit fade stays 260ms; reduced-motion path stays near-instant + no sound.
- Persistence: seen-flag moves from sessionStorage → **localStorage** (same key `aura.welcomeCurtain.seen`; everyone sees the new splash one final time, then never again on that device).
- Sound: chime now plays only on explicit unmute click (browsers block autoplay anyway; the hidden pointerdown gesture was odd UX). Sound toggle + persistence unchanged.
- Honor `useMotionMode().effectiveMotionMode === 'minimal'` alongside `prefers-reduced-motion` for the static path (keeps tested `is-reduced-motion` class).
- Keep: `data-testid="premium-welcome-curtain"`, `role="dialog"`, aria-label, Skip (auto-focus + focus restore), Escape-to-close, `is-closing` class, both env flags.

**2. New `app/src/components/welcome/PremiumWelcomeCurtain.css`** (colocated, like `LoginView.css`): backdrop glow, gradient hairline, shimmer line, entrance keyframes, reduced-motion overrides — all via theme tokens, no hardcoded off-palette hex.

**3. i18n cleanup**: remove `welcomeCurtain.message.thanks` / `welcomeCurtain.message.ready` from `stableUiMessages.js`, `messages/reviewed/en.json`, and the market packs (mechanical), then run the app's i18n scripts to regenerate/verify compiled catalogs. All other keys unchanged.

**4. Update `PremiumWelcomeCurtain.test.jsx`**: storage assertions → localStorage; drop rotation-era expectations; auto-close window 3600 → 2200; chime-failure test now triggers via unmute click; add a "not shown again on later loads (localStorage)" case.

**5. Dark-theme skeletons — `app/src/components/shared/SkeletonLoader/index.jsx`**: `bg-white` → `bg-card`, `bg-gray-200` → `bg-muted`, add `border border-border/60`; keep component API and `animate-pulse` (semantic shadcn tokens make it correct in both dark and light color modes).

**6. Kill the double loader — `app/src/App.jsx:309-315`**: replace the 80vh spinner Suspense fallback with a card-grid `SkeletonLoader` fallback, so chunk-load and data-load read as one continuous skeleton phase (the splash already overlays Home while it mounts).
